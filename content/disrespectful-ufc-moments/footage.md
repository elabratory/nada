## Music

Put a royalty-free, no-copyright track at `music.mp3`. It loops under the whole video at 18% volume. Good sources are the YouTube Audio Library (free in YouTube Studio) or Epidemic Sound. Use something hard-hitting like trap or phonk. Without the file, the video renders with fight audio only.

## Build the video

```bash
node scripts/build-compilation.mjs content/disrespectful-ufc-moments          # final quality
node scripts/build-compilation.mjs content/disrespectful-ufc-moments --fast   # quick preview
```

Output: `content/disrespectful-ufc-moments/disrespectful-ufc-moments.mp4` (1920×1080, 30 fps).
Any clip that isn't in `clips/` yet shows as a red "CLIP NEEDED" slide, so you can preview the full edit before you have all the footage.

### Timeline fields you can tweak (per clip)

| Field | What it does |
|-------|--------------|
| `start` | Where the moment starts in *your* file (`"2:41"` or seconds) |
| `duration` / `end` | How long to use |
| `speed` | `0.5` = slow-mo replay |
| `freezeEnd` | Seconds to hold the last frame (freeze on the KO) |
| `volume` / `mute` | Fight audio level |
| `label` | Small top-left fight name |
| `texts` | On-screen text: `at` (seconds into the clip), `duration`, and `style`: `caption` (bottom) or `punch` (big, orange, centre) |

## Copyright heads-up

UFC footage is copyrighted and the UFC claims it aggressively. A compilation with no voiceover has a weaker fair-use case than commentary, so expect Content ID claims (usually monetisation going to the UFC, sometimes a block). The on-screen text helps. Short clips help too: keep each one to the moment itself, and don't run long stretches of a fight. Never upload full fights.
